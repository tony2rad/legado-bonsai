Conexión

Pega aquí la URL del Web App y el token que generó setup() en el sheet (pestaña CONFIG).

¿Cómo obtengo estos datos?
  1. Abre el sheet Legado Bonsai — Sistema de Gestión → Extensiones → Apps Script.
  2. Pega el contenido de apps-script/Code.gs, guarda y ejecuta setup.
  3. Implementar → Nueva implementación → Aplicación web → Ejecutar como yo, acceso Cualquier persona. Copia la URL.
  4. El token aparece en la pestaña CONFIG del sheet.

    Cámara 360°

    Enciende la base giratoria, encuadra el árbol dentro de la guía y pulsa Iniciar. La app toma una foto cada intervalo hasta completar la cantidad elegida. Una vuelta completa ≈ fotos × intervalo.

    Gira el árbol un poco entre foto y foto (por ejemplo un cuarto de vuelta si son 4 fotos) y pulsa el botón redondo cada vez. Cuando termines, pulsa Listo.
